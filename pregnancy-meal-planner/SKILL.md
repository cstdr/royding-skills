# Pregnancy Meal Planner

## Overview

**核心原则：所有配餐建议必须基于循证医学（Evidence-Based Medicine）。**

孕期营养建议领域充斥着传统迷思和伪科学，agent 的首要责任是识别并主动纠正。**宁可跳过某个食材，也不能传播错误知识。**

当用户提到以下迷思时，agent 必须主动纠正：
- "喝骨头汤补钙"
- "红枣/红糖补血"
- "以形补形"
- 任何祖辈经验与现代营养学冲突的场景

Plans daily meals for pregnant women, targeting critical prenatal nutrients with safe foods. Outputs a night-before reminder format.

## Cross-Platform Path Convention

数据文件路径由 `$PREGNANCY_SKILL_DIR` 环境变量决定。

| 平台 | 默认路径 |
|------|---------|
| OpenClaw | `~/.openclaw/` |

| Codex | `~/.codex/` |

如果 `$PREGNANCY_SKILL_DIR` 未设定，agent 应使用自己平台的默认数据目录。

## When to Use

**主动触发 — 当用户提到以下任何关键词，立即加载此 skill：**
- "吃"+"明天/今天/后天"
- "食谱/菜单/做什么菜"
- "采购/买菜/买什么"
- "营养/补/对胎儿好"
- "孕期/怀孕/准妈妈"

**禁止跳过的情况：**
- 用户说"赶时间/快" → 必须先检查 profile
- 用户有特殊医学条件 → 必须在计划中体现
- 任何饮食相关请求 → 必须使用格式模板

## 用户状态管理

### 首次使用：收集信息

当用户**第一次**使用此 skill，或说"更新孕期状态"时：

1. 询问以下信息（可分次收集）：
   - 当前孕周（如：16周）
   - 预产期（如：2026-09-15）
   - 口味偏好（喜欢/不喜欢什么菜系、口味偏淡/重）
   - 过敏或忌口（海鲜/坚果/乳制品等）
   - 医生特殊建议（妊娠糖尿病/贫血/增重过快等）
   - 饮食限制（素食/ halal / kosher 等）

2. 将信息保存至 `~/.openclaw/pregnancy-profile.json`：
```json
{
  "lastUpdated": "2026-05-19",
  "currentWeek": 20,
  "dueDate": "2026-09-15",
  "isPlanningPregnancy": false,
  "postpartumWeek": null,
  "preferences": {
    "likes": ["粤菜", "清淡口味"],
    "dislikes": ["辛辣", "太油腻"],
    "allergies": [],
    "dietaryRestrictions": []
  },
  "doctorAdvice": {
    "gestationalDiabetes": false,
    "anemia": false,
    "weightConcern": false,
    "notes": "无"
  }
}
```

3. 后续调用时，**先读取此文件**，根据用户状态个性化配餐。

### 自动阶段检测

每次生成饮食计划前，agent 必须先判断用户处于哪个阶段：

```
判断顺序：
1. 如果 isPlanningPregnancy == true → 备孕阶段
2. 如果 postpartumWeek >= 1 && postpartumWeek <= 4 → 月子期间
3. 如果 currentWeek >= 1 && currentWeek <= 12 → 孕早期
4. 如果 currentWeek >= 13 && currentWeek <= 27 → 孕中期
5. 如果 currentWeek >= 28 → 孕晚期
6. 其他 → 正常
```

**各阶段配餐重点：**

| 阶段 | 判断条件 | 配餐重点 | 饮食雷区 |
|------|---------|---------|---------|
| 备孕阶段 | `isPlanningPregnancy: true` | 叶酸+铁+碘，提前储备营养 | - |
| 孕早期 | 1 ≤ week ≤ 12 | 少食多餐止吐、叶酸为主、碘加强 | 生肉、酒精、高汞鱼 |
| 孕中期 | 13 ≤ week ≤ 27 | 铁+钙+DHA 大幅增加 | 禁止骨头汤当钙源；红肉每周2-3次 |
| 孕晚期 | week ≥ 28 | 蛋白质维持、钙继续补、控盐防水肿 | 粗细搭配；避免纯粗粮加重胀气 |
| 月子期间 | 1 ≤ postpartumWeek ≤ 4 | 高蛋白、补血、铁、钙；汤类易吸收 | 禁止喝浓汤不吃肉 |
| 正常 | 其他 | 均衡饮食、维持体重 | - |

### 状态变更

用户说"我孕周变了"或"医生让我补铁" → 询问具体内容 → 更新文件。

## 科学配餐原则

### 循证医学要求

**所有食材推荐必须满足以下条件之一：**
1. 有可靠营养学数据支撑（USDA/Nutrients 等权威数据库可查）
2. 符合主流孕期营养指南（如中国居民膳食指南/ACOG/IOM）
3. 能够明确解释营养机制

**以下来源不能作为推荐依据：**
- 传统/古法/民间经验（"老祖宗都这么吃"）
- 以形补形类比（"吃核桃补脑"）
- 单一案例证成（"我邻居怀孕就这么吃的"）
- 无数据支撑的"养生"理论

### 高效补钙食材（真实有效来源）

| 食材 | 钙含量（每100g） | 吸收率 |
|------|----------------|--------|
| 奶制品（牛奶/酸奶） | ~120mg | 高 |
| 北豆腐 | ~150mg | 高 |
| 芝麻 | ~975mg | 中高 |
| 小鱼干 | ~550mg | 高 |
| 深绿叶菜（苋菜/、油麦菜） | ~50-150mg | 中 |

**❌ 骨头汤不是钙来源** — 骨头里的钙极难溶于水，浓白汤是脂肪乳化液，含钙量极低。排骨汤可喝清汤，但不能作为补钙手段。

### 高效补铁食材（血红素铁优先）

| 食材 | 铁含量（每100g） | 吸收率 |
|------|----------------|--------|
| 猪肝/鸡肝 | ~20mg | 高 |
| 动物血（鸭血/猪血） | ~30mg | 高 |
| 红肉（牛/羊瘦肉） | ~2-3mg | 高（约20%）|
| 红枣/菠菜 | ~2-3mg | 低（<5%）|

**❌ 红枣/红糖/红糖姜茶补血是伪科学** — 非血红素铁吸收率<5%，远低于血红素铁的20-25%。补血靠动物血、肝脏、红肉。

### 高效补叶酸食材

**叶酸大户（每100g）：**
- 深绿叶菜：菠菜（194μg）、苋菜（187μg）、油麦菜（120μg）、芦笋（149μg）
- 豆类：鹰嘴豆（172μg）、黑豆（181μg）
- 其他：牛肝（330μg）、鸡蛋（113μg）

**❌ 番茄叶酸含量并不突出**（每100g约8μg），远低于深绿叶菜，不应作为叶酸主力来源。

### 粗细搭配原则

孕中晚期子宫压迫肠胃，纯粗粮可能导致胀气：
- 糙米/藜麦与白米搭配，**比例 1:1 或 1:2**（细粮为主）
- 不要三餐纯粗粮
- 消化较弱时增加细粮比例

## 历史记录管理

### 文件位置

`~/.openclaw/pregnancy-meal-history.json`

### 数据结构

```json
{
  "history": [
    {
      "weekOf": "2026-W20",
      "days": {
        "monday":    { "breakfast": "xxx", "lunch": "xxx", "dinner": "xxx", "snack": "xxx" },
        "tuesday":  { "breakfast": "xxx", "lunch": "xxx", "dinner": "xxx", "snack": "xxx" },
        ...
      },
      "adjustments": ["周二不吃三文鱼", "周三加了一次猪肝"]
    }
  ]
}
```

只保留最近 **3 周**的数据，超出部分删除。

### 查阅规则（生成计划前必做）

1. 读取 `~/.openclaw/pregnancy-meal-history.json`
2. 汇总过去 3 周所有已出菜品
3. **主菜（早餐主菜/午餐荤菜/晚餐荤菜）** — 前 2 周内出现过的尽量不重复
4. **同类型做法** — 同一烹饪方式（如"清蒸"）不要连续出现
5. **用户调整过的菜** — 记录在 `adjustments` 中，下次主动规避

### 更新规则

计划执行后（用户未提出反对），agent **自动**将当日菜单追加写入历史。

### 用户调整时

用户说"换成牛肉"或"不要虾" → 立即记录到当日 `adjustments` → 并更新当日历史条目。

## 个人菜品库

用户可以说"把这个菜加到我的菜单库"、"我想吃xxx，加进去"来随时添加自己喜欢的菜品。

### 文件位置

`~/.openclaw/pregnancy-favorite-dishes.json`

### 数据结构

```json
{
  "dishes": [
    { "name": "番茄牛腩面", "category": "dinner", "added": "2026-05-10", "notes": "老公做给我吃" },
    { "name": "虾仁蒸蛋", "category": "lunch", "added": "2026-05-12", "notes": "" }
  ]
}
```

### 支持的操作

| 用户说 | Agent 行动 |
|--------|-----------|
| "把这个加到我的菜单库" | 识别当前计划的菜品，追加写入 `favorite-dishes.json` |
| "我想吃xxx，加进去" | 直接添加，支持描述口味/场景 |
| "我最近想吃酸的" | 把酸味类菜品（番茄、柠檬、酸笋）优先列入候选 |
| "我的菜单库里有什么" | 读取文件，列出所有收藏 |
| "从菜单库去掉xxx" | 从文件中删除该条目 |

### 生成计划时的优先级

生成当日计划前，agent 按以下顺序组合菜单：
1. **个人收藏菜品**（来自 `favorite-dishes.json`，且不在历史重复列表中）
2. **未出过的新菜**（保证 2-3 周不重复）
3. **营养补强菜品**（针对用户当前孕期需求）

## 孕期关键营养素（每餐覆盖）

| 营养素 | 作用 | 食物来源（循证优先） |
|--------|------|-------------------|
| **叶酸 (Folate)** | 神经管发育，预防缺陷 | 深绿叶菜（菠菜/苋菜）、豆类、藜麦 |
| **铁 (Iron)** | 预防孕期贫血 | 动物血、肝脏、红肉（高效血红素铁）|
| **钙 (Calcium)** | 胎儿骨骼牙齿 | 奶制品、北豆腐、芝麻、小鱼干 |
| **DHA** | 大脑视网膜发育 | 三文鱼、鲈鱼、沙丁鱼（每周2-3次，低汞）|
| **碘 (Iodine)** | 甲状腺，大脑发育 | 紫菜、海带、加碘盐 |
| **维生素D** | 钙吸收 | 三文鱼、蛋黄、阳光、强化奶 |
| **胆碱 (Choline)** | 大脑发育 | 鸡蛋、牛肉、鸡胸肉 |
| **锌 (Zinc)** | 免疫，细胞分裂 | 贝类、牛肉、南瓜子 |

## 孕期禁忌（必须检查）

**绝对避免：**
- 生或半生肉（生鱼片、生蚝、生肉）
- 未经巴氏消毒的奶酪
- 酒精
- 高汞鱼类（旗鱼、鲨鱼、王鱼、马林鱼）
- 咖啡因 > 200mg/天

**谨慎食用（需控制频率）：**
- 深海大型肉食鱼（每周 ≤ 2次）
- 动物内脏（每周 ≤ 1次，维A过量风险）

## 配餐原则

1. **每餐必有蛋白质** — 胎儿/身体需要氨基酸
2. **每天一种深绿叶菜** — 叶酸主力（菠菜/油麦菜/苋菜等），不是番茄
3. **每天一种富铁食物（血红素铁优先）** — 动物血/肝脏/红肉，预防孕中晚期贫血
4. **每天一种富钙食物** — 奶制品/北豆腐/芝麻，不是骨头汤
5. **omega-3 每周 2-3次** — 低汞海鱼（三文鱼/鲈鱼/沙丁鱼）
6. **少食多餐** — 孕晚期胃被压迫，正餐七分饱
7. **粗细搭配** — 糙米/藜麦与白米比例 1:1 或 1:2，避免纯粗粮

**特殊医生建议优先：**
- 妊娠糖尿病 → 控碳水、选择低GI食材、避免甜食
- 贫血 → 铁摄入翻倍、搭配维生素C促吸收、避免茶咖啡
- 增重过快 → 控糖控油、加大蔬菜比例、选择蒸煮

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 喝骨头汤补钙 | 吃奶制品/北豆腐/芝麻；汤可喝清汤但不能作为钙来源 |
| 喝汤不吃肉 | 优先吃肉，汤适量；汤里营养密度低 |
| 红枣/红糖补血 | 动物血/肝脏/红肉（血红素铁吸收率20-25%）|
| 番茄代替深绿叶菜补叶酸 | 深绿叶菜（菠菜/苋菜）叶酸密度是番茄的20倍以上 |
| 水果代替蔬菜 | 必须吃蔬菜；水果果糖高，叶酸密度远低于蔬菜 |
| 深海鱼多多益善 | 每周≤2次；高汞鱼（旗鱼/鲨鱼）绝对禁止 |
| 三餐纯粗粮 | 粗细搭配（白米:糙米=2:1）；纯粗粮加重孕中晚期胀气 |

## Red Flags — STOP 和 Skill 要求相悖

**以下情况必须使用此 skill，不可跳过：**
- 用户问"明天/今天吃什么"
- 用户需要采购清单
- 用户请求营养建议
- 用户说"快/赶时间" — 压力下更不能跳过 profile 收集或格式

**循证强制要求：**
- **任何食材推荐必须有可靠营养学依据**
- **禁止推荐骨头汤/浓汤作为主要营养来源** — 这是脂肪乳化液，不是营养汤
- **禁止用传统迷思（如"以形补形"）作为食材推荐依据**
- **禁止省略"孕期营养"字段**

**格式强制要求：**
- 必须使用上面的"输出格式模板"，不得改写、简化或省略
- 禁止用纯文字段落替代模板结构
- 禁止省略"孕期营养"字段（哪怕你觉得"简单说"就行）

**Violating the letter of the format is violating the spirit of the format.**
